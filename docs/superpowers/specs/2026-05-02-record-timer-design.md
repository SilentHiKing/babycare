# 计时控件业务逻辑整改设计（历史方案已替换）

原日期：2026-05-02。修订：2026-09-20。

原方案采用“睡眠与活动包含暂停时间”，现已由用户确认的新规则替换，禁止据此恢复旧算法。当前实现规范以 [公共计时器规则与数据模型](../../timer-rules-and-data-model-proposal-2026-09-20.md) 为准。

- 所有类型都扣除用户明确记录的暂停。
- 原业务行从开始到完成保持同一 ID，状态与结构化片段持久在原表中，不新增表。
- 停止先提交，最终完成失败保留停止时刻；正式统计只读已完成数据。
- 母乳按片段记录侧别，睡眠可选记录夜醒，活动可在离页和进程重建后恢复。
- 手工区间、未知过程的总时长、未测时长和计时片段明确区分。
- 公共控件只渲染和采集输入，计时规则由数据层和 ViewModel 管理。
