# BabyCare 全面质量审查与整改

审查分支：`codex/comprehensive-quality-audit`。基线：`43b2161`。已 fetch 远端，当前基线包含 `origin/main` 的全部提交。

## 验收原则

保留「持续记录婴儿生活 → 理解规律 → 参考预测 → 减轻照护负担」的产品理念，以及 Soft Utility 2.0 视觉语言。

将“业内顶尖”拆成可验证要求：已有数据可升级和恢复；记录、暂停和跨日统计一致；提醒不会空转或误发；缺少数据时不制造确定性；主要操作可恢复；浅深色和男女主题可读；真机主要流程可完成。

参照 [Android 核心应用质量指南](https://developer.android.com/docs/quality-guidelines/core-app-quality) 的状态保留、稳定性、触控与对比要求，并参考 [Huckleberry 官方产品说明](https://huckleberrycare.com/) 的高频记录、规律洞察和照护减负方向。竞品说明仅用于确定评估维度，不能据此宣称本项目已达到同等质量。没有真实家长可用性研究、留存数据和多设备长期验证，不能客观证明“业内顶尖”。

使用独立合成数据库：两个宝宝，喂养、睡眠、事件每宝宝每类 5,000 / 50,000 条，共 30,000 / 300,000 条。固定最新日期和每天样本数量，5 次预热、50 次轮换，测量真实 Repository / Room 调度、查询与实体映射；不读写用户数据库，也不等同于页面打开时间或 UI 帧耗时。

MI 6 / API 28，50,000 条规模，单位毫秒（p50 / p95）：

| 查询 | v6 基线 | 最终 v8 |
| --- | ---: | ---: |
| 最近 15 条喂养 | 138.88 / 148.48 | 4.74 / 8.14 |
| 当天喂养 | 54.33 / 59.79 | 4.04 / 6.56 |
| 当天交叠喂养 | 57.10 / 58.41 | 33.56 / 41.33 |
| 首页所用 6 条查询 | 470.66 / 484.55 | 77.08 / 101.99 |
| 当天摘要 | 280.30 / 288.46 | 76.91 / 100.57 |
| 周 / 月 / 年查询组合 | 910.77 / 937.25 | 439.12 / 481.14 |

5,000 条规模下，真机首页查询 p50 为 141.99 → 37.27ms。API 35 模拟器的 50,000 条首页查询为 90.63 → 4.38ms。各组返回量一致；另有跨日、跨多年长记录、相同起点及端点边界的完整字段集合与排序等价验证。原 SQL 自动使用索引，没有强制索引提示或按固定最长时长裁剪记录。

v7 中间方案让真机当天交叠查询退化到 120.80ms，已由 v8 的三列索引消除。没有采用仅强制结束时间索引的方案，因为它会明显拖慢最早历史窗口。交叠查询仍扫描开始时间前缀，不能宣称任意历史规模下均为常数耗时。

代价与测量边界：同样的新建 300,000 条样本库，已分配页容量由 51.145 增至 63.543MiB（约 +24.24%，不含 WAL / SHM）；没有单独测量写入性能。升级后旧索引页可复用，未强制 VACUUM，不承诺文件立即缩小。v6 / v7 为 21 项轮换、v8 抽样 6 项；运行时间、温度与调度不同，因此微小差异不作为确定结论。完整日志、执行计划、容量及复现说明保存在本地 `build/audit/android-room-query-final-v8.md`、`android-overlap-query-comparison.md` 与相邻归档。

## 产品能力差距与验证边界

- 家庭共享仍是“敬请期待”，不能视为已具备多照护者协作；同步服务、账号和冲突策略应作为独立产品项目设计。
- 预测为本地规则估计，需要持续记录与真实使用验证，不代表临床判断或确定的作息安排。
- API 28 真机用于历史升级与 MIUI 兼容；Android 15 模拟器用于补充新系统验证。模拟器不能替代最新平台、折叠屏和平板实机的长期验证。
- 旧计时记录只保存总有效时长，没有完整暂停片段；跨日统计按持续区间比例分配有效时长，保证分日合计守恒，不能恢复历史暂停发生在哪一天。
- 新增记录已通过持久化草稿回执保证同一请求不重复写入；验证包含真实杀进程后表单恢复，以及提交后重开数据库/新建 VM 的重试。没有用不确定的定时杀进程伪称精准命中 SQLite 提交瞬间；两类验证分别覆盖系统恢复与事务一致性边界。
- 需要家长实际完成夜间单手记录、补记、切换宝宝和恢复备份等任务的可用性研究；本次工程审查无法替代该证据。
