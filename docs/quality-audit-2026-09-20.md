# BabyCare 全面质量审查与整改

审查分支：`codex/comprehensive-quality-audit`。基线：`43b2161`。已 fetch 远端，当前基线包含 `origin/main` 的全部提交。

## 验收原则

保留「持续记录婴儿生活 → 理解规律 → 参考预测 → 减轻照护负担」的产品理念，以及 Soft Utility 2.0 视觉语言。

将“业内顶尖”拆成可验证要求：已有数据可升级和恢复；记录、暂停和跨日统计一致；提醒不会空转或误发；缺少数据时不制造确定性；主要操作可恢复；浅深色和男女主题可读；真机主要流程可完成。

参照 [Android 核心应用质量指南](https://developer.android.com/docs/quality-guidelines/core-app-quality) 的状态保留、稳定性、触控与对比要求，并参考 [Huckleberry 官方产品说明](https://huckleberrycare.com/) 的高频记录、规律洞察和照护减负方向。竞品说明仅用于确定评估维度，不能据此宣称本项目已达到同等质量。没有真实家长可用性研究、留存数据和多设备长期验证，不能客观证明“业内顶尖”。

### 16KB 与验证环境

按 [Android 16 行为变更](https://developer.android.com/about/versions/16/behavior-changes-16) 验证目标版本的系统返回与边到边行为，并按 [16KB 内存页说明](https://developer.android.com/guide/practices/page-sizes) 检查原生库与实际运行环境。arm64-v8a / x86_64 原生库的 LOAD 对齐为 `0x4000`；Release 的 `zipalign -c -P 16 4` 检查通过。实际 AVD 通过 `getconf PAGE_SIZE` 确认为 16384，不能把普通 4KB AVD 作为替代证据。

### 图标资源与兼容策略

MIUI 的 PackageManager 返回系统预栅格化的 182px 位图，直接资源仍是自适应矢量。初次同坐标像素检查只有 92.5%，诊断确认参考笔画包围框仅上缘差 1px，质心差约 0.28px，双向 1px 邻域匹配均为 100%。最终仅系统位图路径允许固定 1px 重采样误差，并约束颜色、边界和质心；直接资源仍保留原 98% 同坐标检查。六项错轮廓、实心、缩放和裁剪负对照均须被拒绝，不做自动缩放或平移来迎合结果。

分隔符的前后空格按 [Android 字符串转义规则](https://developer.android.com/guide/topics/resources/string-resource) 使用 `\u0020`，避免只看 XML 源码误以为实际界面已有空格。格式修复均从 Excel 生成，未在 Mapper 拼接额外硬编码文案。
